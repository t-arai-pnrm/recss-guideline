Strength

私たちの強み

  • 運用まで考えた設計

    公開後に社内で更新しやすいよう、CMSの入力項目から設計します。

  • 読み手から決める構成

    サイトを訪れる人の目的から、ページの構成と導線を決めます。

    公開後も、アクセス解析の数字をもとに改善を続けます。

Flow

制作の流れ

  1. ヒアリング

    サイトの目的と、今の課題をお聞きします。

  2. ご提案とお見積り

    サイトの構成と費用をご提案します。

  3. デザイン

    トップページと主なページのデザインを作ります。

  4. 実装

    CMSに組み込み、公開の準備をします。

  5. 公開と運用

    公開後も、更新と改善をお手伝いします。
