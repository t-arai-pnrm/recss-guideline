# 書籍版の組版

「RECSSガイドライン」の紙の書籍版を、サイトのビルド結果（`dist/`）から組む。原稿の正本は MDX のままで、ここでは紙に合わせた書き換えだけをする。

## 使い方

```sh
pnpm build                                   # サイトを作り、dist/ を最新にする（ルートで実行）
pnpm --filter recss-guideline-book html # out/vol1/ に章ごとの HTML と Vivliostyle の設定を作る
pnpm --filter recss-guideline-book pdf  # out/vol1.pdf を作る
```

巻を選ぶときは、`node src/build.mjs 2` のように番号を渡す。確認のために組むページを絞るときは、`BOOK_PAGES=values/if-and-attr,layout/sizing` のようにページの ID を渡す。巻は章ごとのファイルに分けて組む（1つの大きな HTML にすると、組版の時間が文書の大きさに対して急に延びる。巻1は1つのファイルで約20分、章ごとで約1分半）。デモの撮影と PDF には Google Chrome を使う。場所が違う場合は、環境変数 `CHROME_PATH` で指定する。`out/` は git の管理外。

## 設定

- `config/volumes.mjs`：巻と章の対応、巻のタイトル、巻3に載せる付録、扉の後の「この巻について」（前提、到達目標、確かめる問い、次の巻）の文、命名の早見表を前付けに写すか（`cheatSheet`）。早見表は「最小の構成で始める」の同じ見出しから写すので、原稿を直せば紙にも反映される
- `config/demo-selection.json`：デモ（`src/demos/` のディレクトリ名）ごとに、紙に静止図を載せるか（`print`）と、撮る幅（`widths`、省略するとデモの幅のボタンから狭い幅と広い幅を選ぶ）
- `config/code-selection.json`：紙で抜粋する長い設定のタイトル、行の範囲、全文の取得案内。Web版のコードは変えない。原稿を更新したら、抜粋が説明と一致するかを見直す。

## 紙での書き換え

- 内部リンクは、同じ巻なら「（p.N）」、別の巻なら「（巻N）」を付ける。採録しない付録は「補足サイト」とし、試し組みで外した節にはページ番号を付けない。前提の案内は本文に残し、関連資料の参照は節末の注にまとめる。
- デモは、静止図にして「図N-M」を付けるか、「デモN-M（補足サイト）」の1行にする。デモのコードのタブは載せない。
- `Figure` の図は、SVG の `<title>` をキャプションにして番号を付ける。
- 図、表、コードに、章内で一意な番号を付ける。図は静止デモと概念図を掲載順に数える。
- 各節の「ガイドライン」は、強度、要点、性質、適用条件（補足）、IDを残す。理由と自動チェックの詳細は本文とWeb版で引く。
- 章の判断問題と手を動かす課題の答えは、節の後方に解答欄を作り、改ページして刷る。問題から解答欄への参照にはページ番号を付ける。
- 巻末に索引を置く。語は、用語集（付録E）の語と、節の見出しに書いた CSS の構文から拾う。節ごとに、用語集が詳しい説明として指す節（太字）、見出しにその語がある節、本文に3回以上出る節だけを載せる。漢字を含む語の読みと、本文で探す表記は `config/index-terms.json` に書く。

## 版に対応する配布物

ルートの`pnpm build`は`pnpm gen:samples`を先に実行する。版別のZIPとmanifestは`public/sample-files/`に保存し、展開先と`public/book-support/index.html`はビルド時に生成する。ZIPとmanifestはGitで管理して古い版も配信に残す。正式版（1.0以降）の同じ版の内容を変更した場合は、生成を拒否する。

紙面のデモ番号は「節番号-掲載順」で、補足サイトの一覧と`manifest.json`にも載せる。デモの共通トークン、リセット、必要なJavaScriptをHTMLに含める。配布物のpractical/は4-3と同じViteの例で、依存する版を固定する。

冒頭に補足サイトのURLとQRコード、版、対応データの確認年月、依存関係、ライセンスを載せる。QRコードの正本は`public/book-support/qr.svg`。URLを変更したら、QRコードを再生成して読み取りを確かめる。PDF生成の一時ファイルは各巻のout/内へ出す。

`pnpm --filter recss-guideline-book test`で、採録しない参照、適用条件、解答の分離、図番号、前提案内の保持を検査する。静止図は通常状態の抜粋で、実機・全状態の検証を代替しない。判型とカラー方針は現行の182×235mm・カラーを維持している。
