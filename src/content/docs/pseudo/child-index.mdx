`:first-child` や `:nth-child()` は、兄弟の中で何番目にあるかによって要素を選ぶ擬似クラスです。表の縞模様や、一覧の先頭の数件だけを目立たせる処理を、HTMLにクラスを足さずに書けます。本書では、クラスや状態で絞った中での順番を `:nth-child(N of S)` で書き、`:nth-of-type()` を代わりに使いません。

位置で選ぶのは、縞模様のように順番そのものが条件になる場面だけです。役割の決まった子は、タイプセレクタか子クラスで選びます。この節では、位置で選ぶ擬似クラスが何を数えるのか、`An+B` の式の読み方、`of S` で数える対象を絞る方法を順に説明します。位置を値として返す `sibling-index()` と `sibling-count()` も取り上げます。

## 何を数えるかで結果が変わる

位置で選ぶセレクタの誤りは、たいてい「何を数えているか」の取り違えから生まれます。たとえば、商品の表を絞り込み、在庫のない行に `hidden` 属性を付けて隠したとします。行に `:nth-child(even)` で背景を付けていると、隠した行も兄弟として数えられるので、見えている行の縞が崩れます。

```css title="🙅‍♂ Not Recommended: 隠した行も数えて、縞が崩れる" issue="behavior"
/* 🙅‍♂ Not Recommended */
tr {
  &:is(tbody *):nth-child(even) {
    background-color: color-mix(in oklab, var(--foreground--base) 7%, transparent);
  }
}
```

次のデモでは、7行のうち2行目と5行目に `hidden` 属性を付けています。見えている行は1、3、4、6、7行目で、背景が付くのは4行目と6行目です。見えている順に数えると、1つ目と2つ目が続けて無地になり、3つ目と4つ目が続けて色付きになります。

<Demo title="隠した行も数えるので、見えている行の縞が崩れる" html={tableHtml} css={tableBadCss} variant="not-recommended" />

クラスで絞った中での順番を選ぼうとして、`:nth-of-type()` を使う誤りもよく見かけます。`._post:nth-of-type(2)` は「2番目の `._post`」を選ぶように見えますが、`:nth-of-type()` が数えるのはタグ名だけです。この書き方の意味は、後ろの見出しで説明します。

数える対象には、目に見えない要素も入ります。たとえば、カードの先頭に `<template>` や `<script>` を置くと、その要素が最初の子になり、`:first-child` は見出しや画像に当たらなくなります。どの擬似クラスも、ブラウザが表示しているかどうかではなく、DOMの兄弟の並びで数えます。

## 先頭、末尾、ひとりだけの子

もっとも単純な擬似クラスは、`:first-child`、`:last-child`、`:only-child` の3つです。`:first-child` は兄弟の中で最初の要素、`:last-child` は最後の要素、`:only-child` は兄弟を持たない要素に当たります。`:only-child` は、`:first-child:last-child` と同じ要素を選びます。

```css title="🙆‍♂ Recommended: カードが1枚だけのときは、すべての列にまたがらせる" from="pseudo/only-child-grid"
@scope (.scoped.card-grid) to (.scoped) {
  :scope {
    display: block grid;
    grid-template-columns: repeat(auto-fill, minmax(min(100%, calc(120 / 16 * 1rem)), 1fr));

    & > :only-child {
      grid-column: 1 / -1;
    }
  }
}
```

次のデモでは、同じCSSのグリッドを2つ並べています。カードが3枚の一覧では1枚ずつ列に収まり、1枚だけの一覧では、そのカードが `:only-child` に当たって行の幅いっぱいに広がります。幅を375pxにすると列が2つになり、3枚の一覧では3枚目が次の行に回ります。768pxでは列が増え、3枚は1行に並びます。どちらの幅でも、1枚だけのカードは行の幅いっぱいに広がったままです。

<Demo title="兄弟のいないカードだけが、すべての列にまたがる" html={onlyChildHtml} css={onlyChildCss} widths={[375, 768]} />

この3つには、`:first-of-type`、`:last-of-type`、`:only-of-type` という対になる擬似クラスがあります。こちらは、同じタグ名の兄弟だけを数えます。`p:first-of-type` は、前に見出しや画像があっても、兄弟の中で最初の `p` に当たります。

詳細度は、どれも擬似クラス1つ分の0.1.0です。`li:first-child` なら、`li` の0.0.1を足して0.1.1になります。`@scope` の中でタイプセレクタに付けると、子クラスの0.1.0より高くなるので、子クラスで上書きするつもりの宣言が負けないかに気を付けます。詳細度の数え方は「[4-1 カスケード・詳細度・継承](/cascade/cascade-basics/)」で説明しています。

## `An+B` の式の読み方

`:nth-child()` の引数には、`An+B` の形の式を書きます。`n` に0、1、2…と0以上の整数を順に入れ、計算した値が1以上になる位置の要素が選ばれます。位置は1から数えます。`:nth-child(3n+1)` なら、`n` が0、1、2のときに1、4、7となり、1番目、4番目、7番目の子が選ばれます。

`2n + 1` と `2n` には、それぞれ `odd`（奇数番目）と `even`（偶数番目）というキーワードがあります。縞模様のように意味がそのまま伝わる場面では、キーワードで書きます。`A` を省いて `:nth-child(3)` と書けば、3番目の子だけに当たります。

`A` を負の数にすると、先頭から数個を選べます。`:nth-child(-n + 3)` は、`n` が0、1、2のときに3、2、1となり、`n` が3以上では0以下になるので、先頭の3個に当たります。反対に、`:nth-child(n + 4)` は4、5、6…となり、4番目以降のすべてに当たります。式の `B` は境界の位置を、`n` の符号はその先と手前のどちらへ伸びるかを表します。こう読めば取り違えません。

範囲を選ぶときは、2つの `:nth-child()` を連結します。`:nth-child(n + 4):nth-child(-n + 6)` は「4番目以降」と「6番目まで」の両方を満たす要素なので、4番目から6番目に当たります。セレクタを連結すると、それぞれの条件のAND（両方を満たす）になるからです。

```css title="🙆‍♂ Recommended: 新着の先頭3件の日付を強調する" from="pseudo/nth-child-first-three"
@scope (.scoped.news-list) to (.scoped) {
  time {
    /* 先頭から3件の項目の中 */
    &:is(li:nth-child(-n + 3) *) {
      color: var(--foreground--base);
      font-weight: var(--font-weight--bold);
    }
  }
}
```

次のデモでは、5件のお知らせのうち、先頭の3件の日付だけが濃い色の太字になり、4件目と5件目の日付は灰色のままです。

<Demo title="先頭から3件の項目の日付だけを強調する" html={firstThreeHtml} css={firstThreeCss} widths={[]} />

`:nth-last-child()` は、同じ式で末尾から数えます。`:nth-last-child(-n + 2)` は最後の2個、`:nth-last-child(n + 3)` は最後の2個を除いたすべてです。`:nth-child(-n + 3)` のような式は、書いた本人でも数か月後には読み直すのに時間がかかります。上の例のように、選ぶ範囲を文章にしたコメントを添えます。

## `of S` で数える対象を絞る

Selectors Level 4では、`:nth-child()` と `:nth-last-child()` の引数に `of S` を続けられます。`:nth-child(even of :not([hidden]))` は、兄弟のうち `:not([hidden])` に当てはまる要素だけを数え、その中で偶数番目のものを選びます。Sに当てはまらない兄弟は、数える対象から外れます。

この書き方で、最初の見出しの表を直します。`hidden` 属性の付いていない行だけを数えるので、隠した行がいくつあっても、見えている行は1行おきに色が付きます。HTMLは前のデモと同じで、CSSの `:nth-child()` の引数だけを変えています。

```css title="🙆‍♂ Recommended: 隠した行を除いて数え、縞を付ける" from="pseudo/striped-table"
@scope (.scoped.stock-table) to (.scoped) {
  tr {
    &:is(tbody *):nth-child(even of :not([hidden])) {
      background-color: color-mix(in oklab, var(--foreground--base) 7%, transparent);
    }
  }
}
```

<Demo title="hidden 属性の付いていない行だけを数え、縞を付ける" html={tableHtml} css={tableCss} />

Sには、クラス、属性、擬似クラスを含むセレクタのリストを書けます。`:nth-child(-n + 3 of ._pickup)` は「`._pickup` の中で先頭から3個」、`:nth-child(1 of :checked)` は「チェックされたものの中で最初の1個」です。詳細度は、擬似クラス1つ分にSの中でいちばん高いセレクタの詳細度を足した値です。`:nth-child(even of :not([hidden]))` は、0.1.0に `[hidden]` の0.1.0を足して0.2.0になります。

Sが判定するのは、セレクタに当てはまるかどうかだけです。メディアクエリやクラスで `display: none` にした要素は、Sで除かない限り数えられます。{/* 要確認: 出典なし */}表示を切り替える手段を `hidden` 属性にそろえておけば、`:not([hidden])` の1つで、隠した要素を数えずに済みます。

`of S` は、Chrome 111、Safari 9、Firefox 113から使え、2023年5月から主要なブラウザで使えます。Safariは長く先行して対応しており、Firefoxの対応が最後でした。

## `:nth-of-type()` との違い

`:nth-of-type()` は、同じタグ名の兄弟だけを数える擬似クラスです。式の書き方は `:nth-child()` と同じで、`p:nth-of-type(2)` は兄弟の中で2番目の `p` に当たります。数える単位はタグ名に限られ、クラスや属性では数えません。

そのため、`._post:nth-of-type(2)` は「2番目の `._post`」を選びません。この式は「同じタグ名の兄弟の中で2番目にあり、かつ `._post` でもある要素」を選びます。次のHTMLでは、2つ目の `li` が `._ad` なので、`._post:nth-of-type(2)` に当たる要素はありません。

```html
<ul>
  <li class="_post">…</li>
  <li class="_ad">…</li>
  <li class="_post">…</li>
</ul>
```

```css title="🙅‍♂ Not Recommended: 「2番目の ._post」のつもりで :nth-of-type() を使う" issue="behavior"
/* 🙅‍♂ Not Recommended */
._post:nth-of-type(2) {
  /* 2つ目の li は ._ad なので、どの要素にも当たらない */
  border-block-start: 1px solid;
}
```

「2番目の `._post`」を選ぶなら、`:nth-child(2 of ._post)` と書きます。`._post` だけを数えるので、間に広告の `li` が入っても、3つ目の `li` が選ばれます。クラス、属性、状態のどれで絞るときも同じ形で書けるので、本書では、絞った中での順番はすべて `of S` で書きます。

```css title="🙆‍♂ Recommended: :nth-child(2 of ._post) で、2番目の ._post を選ぶ"
@scope (.scoped.post-list) to (.scoped) {
  li {
    &:nth-child(2 of ._post) {
      border-block-start: 1px solid;
    }
  }
}
```

次のデモでは、同じ3つの `li` に、左は `._post:nth-of-type(2)`、右は `:nth-child(2 of ._post)` で枠線と背景色を付けています。左はどの項目にも色が付かず、右は3つ目の「記事B」に色が付きます。

<Demo title=":nth-of-type() はタグ名で数え、of S はクラスで絞って数える" html={nthOfTypeHtml} css={nthOfTypeCss} variant="neutral" widths={[]} />

`:nth-of-type()` が適しているのは、種類の違う要素が混ざった並びで、ある種類の何番目かを選ぶときです。記事の本文で最初の `p` だけ文字を大きくする、といった場面では、`p:first-of-type` のほうが意図をそのまま表します。ただし、本書の規約ではタイプセレクタの順番に頼る場面自体が多くありません。

## 位置を値にする `sibling-index()` と `sibling-count()`

ここまでの擬似クラスは、位置を条件にして要素を選ぶものでした。`sibling-index()` と `sibling-count()` は、位置そのものを値として返す関数です。`sibling-index()` は兄弟の中で何番目かを、`sibling-count()` は自分を含む兄弟の数を、どちらも整数で返します。`:nth-child()` と同じく1から数えるので、最初の子の `sibling-index()` は1です。

返す値は整数なので、`calc()` の中で角度や時間に変えられます。項目ごとに色相を少しずつずらす指定は、`:nth-child()` で書くと項目の数だけルールが要りますが、`sibling-index()` なら1つの式で済み、項目を足しても式を書き足す必要がありません。同じ式で `animation-delay` を項目ごとに遅らせれば、項目が順に現れる演出も書けます。ずらす間隔と、動きを減らす設定との組み合わせは、第18章「[18-8 重ねて出すパネルと順に出す要素](/motion/overlays-and-stagger/)」で扱います。

<Baseline id="sibling-count" name="sibling-index() と sibling-count()" />

2026年8月にFirefox 154が対応し、主要なブラウザの最新版がそろいました（Chrome 138、Safari 26.2）。ただし、本書の対象のブラウザのうち、Safari 18系の最終版は対応していません。そのため本書では、未対応の環境で失われても困らない装飾の値に限って使い、`@supports` の中に書きます。レイアウトの要に使わないのは、未対応の環境で表示が崩れるからです（「[1-2 ブラウザサポートとプログレッシブ・エンハンスメント](/principles/browser-support/)」）。

```css title="🙆‍♂ Recommended: 対応した環境でだけ、項目ごとに色相をずらす" from="pseudo/sibling-index-hue"
@scope (.scoped.topic-list) to (.scoped) {
  li {
    --_hue: 250deg;

    border-inline-start: 4px solid oklch(60% 0.12 var(--_hue));

    @supports (z-index: sibling-index()) {
      /* 隣り合う項目を見分けやすくするため、位置ごとに色相を変える */
      --_hue: calc(210deg + sibling-index() * 40deg);
    }
  }
}
```

次のデモでは、5つの項目の行頭側に線を引いています。`sibling-index()` に対応したブラウザでは、線の色相が項目ごとに40度ずつずれ、1つ目の青から順に紫、赤紫の側へ変わっていき、未対応のブラウザでは5本とも同じ青の線になります。

<Demo title="対応した環境では、項目ごとに線の色相がずれる" html={siblingHtml} css={siblingCss} widths={[]} scheme="light" />

`@supports` を省くと、未対応の環境で線が消えます。カスタムプロパティは中身を検証せずに受け取るので、`--_hue` には解釈できない式がそのまま入り、それを使う `border-inline-start` が計算値の時点で無効になるからです。`@supports` の中に書けば、未対応の環境ではすべての項目が同じ色相の線になります。線の色は装飾なので、色相がそろっても、項目の内容は文字で伝わります。

数える対象は `:nth-child()` と同じで、`of S` のような絞り込みはありません。`hidden` 属性で隠した項目も兄弟として数えるので、絞り込みのある一覧では、見えている項目の色相が飛び飛びになります。子の数を扱う点では「[5-5 数量クエリ](/pseudo/quantity-queries/)」と似ていますが、役割が違います。数量クエリは「3件以上なら」のように数を条件にして宣言を切り替え、`sibling-count()` は数を式に入れて連続的に変わる値を作ります。件数で見た目を切り替える処理は、本書の対象のブラウザがすべて対応している数量クエリで書きます。

## 位置で選ばないほうがよい場面

位置で選ぶのは、順番そのものが条件になる場面だけです。縞模様、先頭の数件の強調、最後の要素の後ろに区切りを付けない処理などです。役割の決まった子を `:first-child` や `:last-child` で選ぶと、HTMLの順番を入れ替えたり要素を足したりしたとき、スタイルが別の子に当たります。

「[12-6 sidebar：メインとサイドの2カラムにし、狭ければ縦に積む](/compositions/sidebar/)」も、同じ理由で、メインとサイドを `& > :first-child` ではなく専用のクラスで選びます。サイドを先に書く場合があり、位置で選ぶとメインとサイドが入れ替わるからです。役割で区別する子には、`@scope` の中のタイプセレクタか、役割の名前の子クラスを使います。

子要素の間隔も、位置で選んで作りません。すべての子に `margin-bottom` を付けて `:last-child` で打ち消す書き方は、要素の順番を変えるたびに打ち消しの対象を確かめ直すことになります。間隔は親の `gap` で作ります（「[11-2 余白を設計する](/layout-practice/spacing/)」）。見出しや段落が続く本文では、2つ目以降の子に `margin-block-start` を付けるコンポジション `prose` を使います（「[12-2 prose：子ごとに変えられる間隔で、本文の流れを作る](/compositions/prose/)」）。

子の数によってレイアウトを切り替える処理も、`:nth-child()` と `:nth-last-child()` の組み合わせで書けます。`:first-child:nth-last-child(3)` は、兄弟がちょうど3つのときの最初の子です。この書き方は数量クエリと呼ばれ、「[5-5 数量クエリ](/pseudo/quantity-queries/)」で説明します。
