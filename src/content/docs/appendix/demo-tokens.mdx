## 色

色は、プリミティブとセマンティクスの2層に分けています。デモから参照するのはセマンティクスだけです。デモは本のページのテーマに追従するので、セマンティクスには `light-dark()` でライトとダークの両方の値を持たせています。

面の色は、ページ（`base`）、カード（`surface`）、ダイアログ（`overlay`）、メニューやポップオーバー（`raised`）の4段階です。ライトでは `base` 以外を白にし、高さは影で表します。ダークでは影が見えにくいので、高い面ほど背景を明るくします。メニューはダイアログの中でも開くので、`raised` を `overlay` より明るくしています。

枠線は文字色を12%に薄めた色で、ホバーと押下は半透明の重ね色です。どちらも、どの面の上に置いても同じように見えます。文字色は `base` と `muted` の2つだけで、青（accent）はリンク、フォーカスリング、選択した状態にだけ使います（例外は「[デモだけの例外](#デモだけの例外)」）。選んだ状態や範囲を淡く示すときは、半透明の `--background--accent-subtle` を使います。状態色は、エラーの赤と成功の緑だけを持っています。

## 影

影は、段階が上がるほど、オフセットとぼかしを倍にした層を足していきます。どの層も不透明度が同じなので、重なった部分ほど濃くなり、高い要素ほど影が遠くまで落ちます。いちばん低い `xs` は1pxの縁取りだけで、通常の表示での縁取りに使えます。操作できる範囲や情報の区切りを示す境界に使うときは、強制カラーモードで同じ太さの `outline` を描きます（[ルール `no-box-shadow-only-boundary`](/color-media/forced-colors/#rule-no-box-shadow-only-boundary)）。

影の色は、色のトークン（`--shadow--color` など）を参照しています。`box-shadow` の値は `light-dark()` で切り替えられないので、形は1つだけ定義し、各層の色をライトとダークで切り替えています。ダークでは、上辺の白いハイライトと内側の縁取りで面の端を見せます。

`--drop-shadow--*` は、影を動かすときの `filter` の値にする `drop-shadow()` の並びです（「[16-5 面・影・角丸](/decoration/surfaces/)」）。`drop-shadow()` の3つ目の長さはガウスぼかしの標準偏差で、`box-shadow` のぼかし半径とは意味が違います。同じ値では約2倍の距離までぼけるので、ぼかしを `box-shadow` の半分にしています。`drop-shadow()` には広がりと `inset` がなく、並べた関数は前の影を含めた結果に順に影を付けるので、`box-shadow` の独立した層をそのまま置き換えたものにはなりません。そのため、`--shadow--*` の同じ名前の段階と同じ見た目にはなりません。どの段階も関数を2つにそろえているので、どの段階の間でもトランジションできます。色は `--shadow--color` を共有し、縁取りは含めません。

## デモを見せるための足場

デモの枠は、トークンとkiso.cssのほかに、デモを見せるためだけの指定を読み込んでいます。本文の主題ではないので、デモのCSSのタブには出しません。

すべてのデモで、全称セレクタに `min-inline-size: 0` を、`body` に `padding: 24px` と背景色と文字色を指定しています。`min-inline-size: 0` は「[8-2 ベーススタイルに書くもの](/reset/base-styles/)」と同じ指定です。デモのHTMLを自分の環境に写すときは、この余白の分だけ幅が変わります。

比べる区画を並べるデモでは、HTMLの `data-demo-layout="compare"` を付けた要素の直下の区画を、最小幅240px相当の列で横に並べています。狭いときは縦に積みます。各区画の先頭の見出しは、ラベルの大きさ（`--text--body-compact--*`）にしています。区画がコンポーネントのルートなら、その中の配置と見出しはコンポーネントに任せます。区画の幅が結果を左右するデモでは、`data-demo-layout="stack"` で、区画をいつも縦に積みます。

```css title='data-demo-layout の指定'
@layer compositions {
  :is([data-demo-layout="compare"], [data-demo-layout="stack"]) {
    display: block grid;
    gap: 16px;

    /* 直下の子がコンポーネントのルートなら、その中の配置と見出しはコンポーネントに任せる */
    & > :not(.scoped) {
      display: block grid;
      gap: 8px;
      align-content: start;
    }

    & > :not(.scoped) > :is(h2, h3, h4):first-child {
      font-size: calc(var(--text--body-compact--font-size) / 16 * 1rem);
      line-height: var(--text--body-compact--leading);
    }
  }

  [data-demo-layout="compare"] {
    grid-template-columns: repeat(auto-fit, minmax(min(100%, calc(240 / 16 * 1rem)), 1fr));
  }
}
```

要素を枠の端まで届かせるデモでは、`body` の余白を外しています。左右だけを外すデモと、上下左右を外すデモがあります。

## デモだけの例外

デモは、本文の説明を見せるために、本番のCSSでは採らない書き方をすることがあります。次の例外は、デモにだけ認めているものです。デモのCSSを自分のプロジェクトに写すときは、本番の書き方に戻してください。

- 比べるために、複数のコンポーネントを1つのファイルに書くことがあります（[ルール `one-component-per-file`](/components/boundaries/#rule-one-component-per-file)）。そのときは、ファイルの先頭にだけ説明のブロックを置きます。
- 公開プロパティのない解説のデモでは、ファイルの先頭の説明のブロックを省きます。説明は本文が受け持ちます。
- 解説のデモには、比べた結果（「詳細度は0.1.0」など）を示す注釈を書くことがあります。何をしているかを説明するだけの注釈は書きません（[ルール `comments-why-only`](/notation/comments/#rule-comments-why-only)）。
- 当たった要素や、説明の対象の箱を示す図解と、第15章の色そのものを見せる例では、青（accent）をリンク、フォーカスリング、選択した状態のほかにも使います。
- 文字の大きさや行の高さそのものを比べるデモと、図の大きさに合わせて大きさを変える図の中の文字（グラフの数値など）では、役割のトークンを使わずに値を書きます。
- テーマのトークンを定義する書き方を見せるデモと、「[最小の構成で始める](/introduction/quick-start/)」のように本文の構成をそのまま再現するデモでは、トークンを宣言し直します。値は、このページのトークンにそろえています。ただし「最小の構成で始める」では、灰色の背景の上でカードの境界と文字のコントラストを保つため、カードの面と `muted` の文字色、見出しの文字サイズを、その構成の中で決めた値にしています。
- 特定の色を見せるデモは、ライトのテーマに固定し、色の値を直接書きます。
- デモは、横書きで左から右へ書く言語を前提にしています。右から左へ書く言語への対応は、本文が勧めている箇所だけで行っています。

本書のリポジトリでは、`pnpm lint:demos` が、共通トークンの宣言し直し、色のプリミティブの参照、役割のトークンを使わない文字の大きさ、状態のない面へのホバーと押下の色を検出します。上の例外に当たるデモは、検査の対象から外しています。
