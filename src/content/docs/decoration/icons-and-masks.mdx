単色のアイコンは、擬似要素の `mask-image` かインラインSVGで描き、どちらも文字色に合わせて塗ります。マスクで描くなら `background-color` で塗り、インラインSVGなら `fill` や `stroke` を `currentColor` にします。文字色を変えるだけでアイコンも一緒に変わるので、状態ごとにアイコンの色を指定し直す必要がありません。

意味を持つインラインSVGのアイコンには、`role="img"` と `aria-label` で名前を付けます。名前をページ内検索やコピーの対象にしたいときは、SVGを `aria-hidden="true"` にし、隣に視覚的に隠したテキストを置きます。マスク、インラインSVG、外部のファイルを読み込む `<img>` のどれで描くかは、文字色に合わせたいか、HTMLにアイコンを書けるかで選びます。メニューのボタンの三本線も、空の要素を並べず、インラインSVGで描きます。

三角形のような図形を `clip-path` で描く方法と、マスクのグラデーションでスクロールできる領域の端を薄くする方法は、「[16-4 clip-pathとマスクで見せる範囲を決める](/decoration/clipping-and-masks/)」で説明しています。マスクの合成で枠線やドーナツグラフを描く方法は、「[16-9 輪郭と枠線を描く](/decoration/outlines/)」にあります。

## アイコンをマスクで描く

単色のアイコンは、SVGを `mask-image` のマスクにして描けます。テンプレートでは、矢印のアイコンをdata URIのトークン（`--chevron--rightward` など）として定義し、擬似要素の `mask-image` で参照しています。色は `background-color` で塗るので、文字色やホバーの状態に合わせて変えられます。

```css title="🙆‍♂ Recommended: マスクで切り抜き、背景色で塗る"
._more {
  &::after {
    content: "";

    /* 空の擬似要素はインラインになり、幅と高さが効かないので、箱を作る */
    display: inline flow-root;
    mask-image: var(--chevron--rightward);
    mask-repeat: no-repeat;
    mask-position: center;
    mask-size: contain;
    inline-size: 1em;
    aspect-ratio: 1;
    background-color: var(--background--current);
  }
}
```

<Demo title="マスクで描いた矢印が、背景色に合わせた文字色で塗られる" html={maskIconHtml} css={maskIconCss} />

デモの1つ目はページと同じ配色、2つ目は背景と文字の明暗を反転させたセクションです。どちらのセクションでも、リンクの後ろの矢印は、リンクの文字と同じ色で塗られます。

`display: inline flow-root` は、空の擬似要素に幅と高さを持たせるための指定です。親が `display: inline flex` のようなフレックスコンテナなら、擬似要素はフレックスアイテムとしてブロックの箱になるので、この指定は要りません。その代わり、フレックスアイテムの伸び縮みで、アイコンが正方形でなくなります。

```css title="🙆‍♂ Recommended: フレックスアイテムのアイコンを、伸び縮みさせない"
._more {
  display: inline flex;
  gap: 4px;

  &::after {
    content: "";
    flex: none;
    align-self: center;
    mask-image: var(--chevron--rightward);
    mask-repeat: no-repeat;
    mask-position: center;
    mask-size: contain;
    inline-size: 1em;
    aspect-ratio: 1;
    background-color: var(--background--current);
  }
}
```

`align-self` を指定しないと、交差軸の `stretch` で、高さが行の高さまで伸びます。`aspect-ratio` は、高さが伸ばされると使われません。高さ60pxのフレックスコンテナで試すと、`inline-size: 1em` と `aspect-ratio: 1` を指定した20pxのアイコンは、20×60pxになりました。`flex: none` を指定しないと、リンクの文字が折り返すほど親が狭いときに、幅が縮みます。親の幅を60pxにすると、幅は約4pxでした。デモでは、親の `align-items: center` で高さが伸びないので、`flex: none` だけを指定しています。

`background-color` に `currentColor` を直接書かず、`--background--current` から受け取っているのは、強制カラーモードでアイコンを消さないためです。この仕組みは「[15-5 強制カラーモードとコントラスト](/color-media/forced-colors/)」で説明しています。マスクのプロパティは、2023年12月までにすべての主要なブラウザが接頭辞なしで対応したので、`-webkit-` の接頭辞は要りません。

## アイコンは currentColor で文字色に合わせる

インラインSVGのアイコンは、`fill` や `stroke` を `currentColor` にして、文字色に合わせます。ボタンの種類や状態ごとにアイコンの色を指定し直す必要がなくなり、文字色を変えるだけで、アイコンも一緒に変わります。

```css title="🙅‍♂ Not Recommended: 状態ごとにアイコンの色を指定し直す" issue="convention"
/* 🙅‍♂ Not Recommended */
button {
  color: var(--foreground--base);

  &:disabled {
    color: var(--foreground--muted);
  }
}

._icon {
  fill: var(--foreground--base);

  &:is(button:disabled *) {
    fill: var(--foreground--muted);
  }
}
```

```css title="🙆‍♂ Recommended: アイコンは文字色に合わせ、文字色だけを切り替える" from="decoration/current-color-icon"
button {
  color: var(--foreground--base);

  &:disabled {
    color: var(--foreground--muted);
  }
}

._icon {
  fill: currentColor;
}
```

<Demo title="無効なボタンでは、文字色だけを変えると、アイコンと枠線も同じ色になる" html={currentColorHtml} css={currentColorCss} />

デモの1つ目は通常のボタン、2つ目は `disabled` を付けたボタンです。2つ目では文字色を薄い灰色に変えているだけですが、アイコンと枠線も同じ灰色になります。

`border` の色を省略した場合も、初期値は `currentColor` です。文字と同じ色の枠線なら、`border: 1px solid` とだけ書けば足ります。色を2か所に書かなければ、片方だけ変え忘れることもありません。

アイコンの大きさは、`inline-size: 1em` と `aspect-ratio: 1` で文字の大きさに合わせます。デモのボタンのようにフレックスコンテナの中に置くときは、マスクのアイコンと同じく `flex: none` を指定し、交差軸で伸ばさないようにします。テンプレートでは `.icon` というクラスで、`--icon--size` を受け取れるようにしています。アイコンを画面の幅に合わせて変える必要がないことは、「[13-1 検討する順番](/responsive/escalation/)」で説明しています。

線で描くアイコンは、大きさを変えると線の太さも同じ割合で変わります。`stroke-width` は `viewBox` の座標で決まり、SVGを拡大縮小すると座標ごと拡大縮小されるからです。`viewBox="0 0 24 24"` で `stroke-width="2"` のアイコンは、16pxで表示すると約1.3px、48pxで表示すると4pxの線になります。表示する大きさが違っても線の太さを枠線などとそろえたいときは、図形に `vector-effect="non-scaling-stroke"` を書くと、`stroke-width` の値がそのまま画面上のpxの太さになります。

```html
<svg class="icon" aria-hidden="true" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5">
  <path d="M4 12L10 18L20 6" vector-effect="non-scaling-stroke" />
</svg>
```

`vector-effect` は継承しないので、`svg` 要素ではなく、線を描く図形の要素それぞれに書きます。CSSのプロパティとしても指定できますが、図形の要素にはクラスを付けないことが多く、子要素のクラスの下をタイプセレクタで選ぶことになるので（[`no-type-under-child-class`](/components/boundaries/#rule-no-type-under-child-class)）、本書ではHTMLの属性で書きます。大きく表示しても線は太くならないので、大きさに合わせて線を太らせたいアイコンには書きません。Chromeで確かめたところ、15倍に拡大したSVGで、`vector-effect` を書いた線は1px、書いていない線は15pxで描かれました。{/* 要確認: 出典なし。線の太さを固定するアイコンの使い分け */}

### インラインSVGの代替テキスト

意味を持つアイコンをインラインSVGで置くときは、`svg` 要素に `role="img"` と `aria-label` を付けて名前を付けます。`role="img"` を付けると、SVGの中の図形がまとめて1つの画像として扱われ、`aria-label` の値がその名前になります。装飾だけのアイコンや、隣のテキストと同じ意味のアイコンには、`aria-hidden="true"` を付けて読み上げの対象から外します。

```html
<a href="https://example.com/" target="_blank">
  関連資料
  <svg class="icon" role="img" aria-label="新しいウィンドウが開きます" viewBox="0 0 24 24" fill="none" stroke="currentColor">
    <path d="M17 2H22V7" />
    <path d="M13 11L21.5 2.5" />
  </svg>
</a>
```

`aria-label` の値は、Chrome、Edge、Firefox、Safariの翻訳機能とGoogle翻訳では訳されることが確かめられています（参考リンクの検証）。翻訳サービスによっては訳されないものもあります。また、`aria-label` の値は、ページ内検索と、選択してのコピーの対象になりません。

名前をページ内検索で見つけられるようにしたいときや、コピーした文章に含めたいときは、SVGに `aria-hidden="true"` を付け、隣に視覚的に隠したテキストを置きます。視覚的に隠す `.-visually-hidden` の定義は「[17-5 要素を隠す方法を選ぶ](/interaction/hiding-elements/)」に、ユーティリティの扱いは「[10-3 コンポジションとユーティリティ](/components/compositions-and-utilities/)」にあります。

```html
<a href="https://example.com/" target="_blank">
  関連資料
  <svg class="icon" aria-hidden="true" viewBox="0 0 24 24" fill="none" stroke="currentColor">
    <path d="M17 2H22V7" />
    <path d="M13 11L21.5 2.5" />
  </svg>
  <span class="-visually-hidden">新しいウィンドウが開きます</span>
</a>
```

### 単色のアイコンの描き方を選ぶ

単色のアイコンを置く方法は、擬似要素の `mask-image`、インラインSVG、外部のファイルを読み込む `<img>` の3つです。どれを選ぶかは、文字色に合わせたいか、HTMLにアイコンを書けるかで決まります。違いを次の表にまとめます。

| 方法 | 色を文字色に合わせる | 強制カラーモード | 代替テキスト | 向く場面 |
| --- | --- | --- | --- | --- |
| 擬似要素の `mask-image` | `background-color` で合わせられる | 背景色が消えるので、`--background--current` でシステムカラーに戻す | `content` の代替テキストで付けられるが、ページ内検索の対象にならないので、意味があれば隣にテキストを置く | 矢印や外部リンクの印のように、CSSだけで足す装飾 |
| インラインSVG | `fill` や `stroke` の `currentColor` で合わせられる | 色が置き換わらないことがあるので、`fill` と `stroke` をシステムカラーに固定する | `role="img"` と `aria-label` で付ける。ページ内検索の対象にしたいときは、`aria-hidden="true"` にして隣に視覚的に隠したテキストを置く | 意味のあるアイコンや、線と塗りを使い分ける複雑な形 |
| 外部のファイルの `<img>` | 合わせられない。画像の中の色のまま | 影響を受けないので、背景に溶け込むなら `filter` で塗りつぶす | `alt` 属性で付ける | 色を変えないロゴや、多色の画像 |

{/* 要確認: 出典なし。「向く場面」の列と、<img> のSVGがページの文字色を受け取らないこと */}

擬似要素の `content` には、`content: "" / "新しいウィンドウが開きます"` のように、スラッシュの後ろに代替テキストを書けます。この文字列は読み上げられますが、ページ内検索の対象になりません。Chrome、Firefox、Safariのどれでも、ページ内検索で代替テキストの文字列は見つかりませんでした。そのため、意味のあるアイコンでは、マスクで描く場合も、隣に視覚的に隠したテキストを置きます。装飾だけのアイコンには、代替テキストを書きません。{/* 要検証: ブラウザ。content の代替テキストが機械翻訳の対象にならないこと（ページ内検索は 2026年10月13日に window.find() で確認済み） */}

文字色に合わせる必要があるアイコンは、`mask-image` かインラインSVGのどちらかになります。HTMLに手を入れずにCSSだけで足したい装飾なら `mask-image` を、HTMLの中で意味を持たせたいアイコンならインラインSVGを選びます。強制カラーモードの補正は、どちらも「[15-5 強制カラーモードとコントラスト](/color-media/forced-colors/)」で説明しています。

## メニューのボタンの三本線をSVGで描く

メニューのボタンの三本線は、インラインSVGで描きます。線を描くためだけの空の要素を並べ、CSSで線にする書き方もありますが、CSSが読み込まれないと何も表示されません。SVGなら、`viewBox` と図形の属性だけで形が決まるので、CSSがなくても三本線が残ります。

```html title="🙅‍♂ Not Recommended: 線を描くためだけの空の span を並べる" issue="convention"
<!-- 🙅‍♂ Not Recommended -->
<button type="button" popovertarget="demo-menu">
  <span class="_line"></span>
  <span class="_line"></span>
  <span class="_line"></span>
  メニュー
</button>
```

この `span` は、CSSで幅、高さ、背景色を与えて初めて線になります。HTMLには形の情報がないので、マークアップを読んでも、何を描いているのかが分かりません。Chromeで、CSSを読み込まないページに2つのボタンを置くと、空の `span` のボタンには文字だけが表示され、SVGのボタンには三本線が表示されました。

```html title="🙆‍♂ Recommended: 三本線をインラインSVGで描き、線の太さと色は属性で書く" from="decoration/menu-icon"
<button type="button" popovertarget="demo-menu">
  <svg class="_icon" aria-hidden="true" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">
    <path class="_line-start" d="M4 6H20" />
    <path class="_line-middle" d="M4 12H20" />
    <path class="_line-end" d="M4 18H20" />
  </svg>
  メニュー
</button>
```

`viewBox`、`fill`、`stroke`、`stroke-width` は、CSSではなく属性で書きます。CSSがなくても、線の太さと色が決まった三本線として表示されるからです。大きさを決めるCSSがないときは、アイコンがボタンの幅まで広がりますが、何のボタンかは分かります。色は `currentColor` にして、ボタンの文字色に合わせます（「[アイコンは currentColor で文字色に合わせる](#アイコンは-currentcolor-で文字色に合わせる)」）。

ボタンの名前は、見える文字の「メニュー」で付け、SVGは隣の文字と同じ意味なので `aria-hidden="true"` にします。アイコンだけのボタンにするときは、SVGではなく、操作する要素の `<button>` に `aria-label="メニュー"` を付けます。

### 開いている間は×に変える

線ごとに `path` を分けておけば、メニューを開いている間、上下の線を回して×にできます。1つの `path` に3本の線をまとめると（`d="M4 6H20M4 12H20M4 18H20"`）、3本を一緒にしか動かせません。

```css title="🙆‍♂ Recommended: メニューを開いている間、上下の線を回して×にし、真ん中の線を消す" from="decoration/menu-icon"
@scope (.scoped.site-menu) to (.scoped) {
  ._line-start,
  ._line-middle,
  ._line-end {
    transform-origin: center;
    transform-box: fill-box;

    @media (prefers-reduced-motion: no-preference) {
      transition-duration: var(--duration--base);
      transition-property: translate, rotate, opacity;
      transition-timing-function: var(--ease--in-out-quint);
    }
  }

  ._line-start {
    &:is(button:has(+ :popover-open) *) {
      translate: 0 6px;
      rotate: 45deg;
    }
  }

  ._line-middle {
    &:is(button:has(+ :popover-open) *) {
      opacity: 0;
    }
  }

  ._line-end {
    &:is(button:has(+ :popover-open) *) {
      translate: 0 -6px;
      rotate: -45deg;
    }
  }
}
```

<Demo title="メニューを開いている間、三本線の上下の線が回って×になる" html={menuIconHtml} css={menuIconCss} height="240px" />

デモのボタンを押すと、ボタンの下にメニューが開き、三本線が×に変わります。Escキーを押すか、メニューの外を押して閉じると、三本線に戻ります。

SVGの図形は、デフォルトでは、`viewBox` の原点（左上）を基準に変形します。`transform-box: fill-box` で基準を図形自身の範囲にし、`transform-origin: center` を合わせると、各線が自分の中心で回ります。上下の線は真ん中の線から6ずつ離れているので、`translate` で6ずつ寄せてから回すと、3本が中心で交わります。SVGの図形に指定した `translate` の長さは `viewBox` の座標で数えるので、アイコンを表示する大きさが変わっても、寄せる量は直さずに済みます。

<Baseline id="transform-box" compatKey="css.properties.transform-box.fill-box" name="transform-box: fill-box" />

開いた状態は、ボタンの直後に置いたポップオーバーが開いているかを、`button:has(+ :popover-open)` で調べて選びます。「[18-4 トランジションの基本と中断](/motion/transitions-and-keyframes/)」のボタンのアイコンを回す例と同じく、`&:is(… *)` で、状態を持つ祖先の下の図形を選んでいます。HTMLの要素と支援技術の対応を定める仕様（HTML-AAM）では、`popovertarget` を付けたボタンは、ポップオーバーが開いているかどうかを支援技術に伝えるとされています。そのため、`aria-expanded` を自分で切り替える必要はありません。{/* 要検証: ブラウザ。Chrome、Firefox、Safari のアクセシビリティツリーで、popovertarget を付けたボタンの展開状態が、ポップオーバーの開閉に合わせて変わること */}トランジションは、`prefers-reduced-motion: no-preference` の中に書きます。動きを減らす設定では、×への切り替えが一度で起きます（「[18-2 動きを減らす設定に対応する](/motion/reduced-motion/)」）。

画面を覆うモーダルのドロワーでは、開いている間、メニューのボタンは背面にあって操作できないので、×に変えても見せる場面がありません。ドロワーの中に閉じるボタンを置きます。ドロワーの開閉は「[17-6 開閉するUI](/interaction/disclosure/)」で説明しています。

## 同じアイコンを何度も置くときのスプライト

同じアイコンをページの中で何度も置くなら、形を `<symbol>` に一度だけ書き、置く場所では `<use href="#id">` で参照します。インラインSVGをそのまま繰り返すと、同じパスのデータが置いた数だけHTMLに並び、形を直すときもすべての箇所を書き換えることになります。`<symbol>` はそれ自体では描画されず、`<use>` で参照された場所にだけ表示されます。{/* 要確認: 出典なし。スプライトを使う場面の判断 */}

```html
<!-- body の先頭に一度だけ置く -->
<svg aria-hidden="true" style="display: none">
  <symbol id="icon-check" viewBox="0 0 24 24">
    <path d="M4 12L10 18L20 6" />
  </symbol>
</svg>

<!-- 置く場所では参照するだけ -->
<svg class="icon" aria-hidden="true" fill="none" stroke="currentColor">
  <use href="#icon-check" />
</svg>
```

`viewBox` は `<symbol>` に書き、表示する大きさは参照する側の `svg` 要素で決めます。大きさを `.icon` の `inline-size: 1em` と `aspect-ratio: 1` で決める点は、インラインSVGと変わりません。色も、参照する側の `svg` 要素に `fill="currentColor"` か `stroke="currentColor"` を書き、`<symbol>` の中の図形には色を書きません。こうすると、図形は `<use>` を通して `svg` 要素の値を継承するので、「[アイコンは currentColor で文字色に合わせる](#アイコンは-currentcolor-で文字色に合わせる)」と同じく文字色に合わせられます。「[15-5 強制カラーモードとコントラスト](/color-media/forced-colors/)」の補正も、`svg` 要素の属性で対象を選ぶので、そのまま当たります。{/* 要検証: ブラウザ。強制カラーモードで、svg 要素の fill と stroke の補正が use で参照した図形に継承されること */}

### `<use>` の中身へのスタイルの届き方

`<use>` で参照した図形は、`<use>` 要素のシャドウツリーに複製されます。外の文書に書いたスタイルのルールは、この複製した要素には当たりません。そのため、`.button path` のように、置いた場所の祖先から中の図形を選ぶことはできません。Chromeで確かめたところ、`.button path` に指定した `fill` は当たらず、図形は `svg` 要素から継承した色のままでした。

```css title="🙅‍♂ Not Recommended: 置いた場所の祖先から、use の中の図形を選ぶ" issue="behavior"
/* 🙅‍♂ Not Recommended */
.button {
  & path {
    fill: var(--foreground--danger);
  }
}
```

一方、`<symbol>` の中の元の図形に当たるルールは、複製した図形にも当たります。ただし、どこに置いた複製にも同じように当たるので、場所ごとに見た目を変える用途には使えません。複製した図形が置いた場所によって変えられるのは、シャドウツリーのホストである `<use>` 要素から継承した値だけです。

### 2色目の色の渡し方

2色目が要るアイコンでは、`<symbol>` の中の図形の `fill` にカスタムプロパティを書き、置く側でその値を指定します。カスタムプロパティは継承するので、`<use>` の外で指定した値が、シャドウツリーの中の図形まで届きます。代替値を `currentColor` にしておけば、指定しない場所では1色のアイコンとして表示されます。Chromeでは、`fill` 属性に書いた `var()` が、置いた場所で指定した値に置き換わりました。{/* 要検証: ブラウザ。Firefox と Safari で、symbol の中の fill 属性に書いた var() が、use の外で指定したカスタムプロパティを受け取ること */}

```html
<symbol id="icon-alert" viewBox="0 0 24 24">
  <circle cx="12" cy="12" r="10" />
  <path fill="var(--icon--secondary-fill, currentColor)" d="M11 6H13V14H11ZM11 16H13V18H11Z" />
</symbol>
```

```css title="🙆‍♂ Recommended: 2色目は、置く側のカスタムプロパティで渡す"
@scope (.scoped.notice) to (.scoped) {
  :scope {
    --icon--secondary-fill: var(--background--base);
  }
}
```

2色目は図形の要素に書いた値なので、15-5の `svg` 要素に対する強制カラーモードの補正は、2色目の図形には届きません。強制カラーモードで1色目と2色目の区別が要るなら、そのコンポーネントの中で、`--icon--secondary-fill` をシステムカラー（`Canvas` など）に指定し直します。図形ごとに違う指定がいくつも要るアイコンは、カスタムプロパティの数が増えて宣言と参照を追いにくくなるので、スプライトにせず、インラインSVGのまま置きます。{/* 要確認: 出典なし。2色目の強制カラーモードでの扱いと、インラインSVGに戻す目安 */}{/* 要検証: ブラウザ。強制カラーモードで、カスタムプロパティで渡した2色目が元の色のまま残ること */}

### 外部のファイルのスプライト

スプライトは外部のSVGファイルにまとめ、`<use href="/icons.svg#icon-check">` のようにファイルの後ろに `#` とIDを付けて参照できます。ファイルはブラウザにキャッシュされるので、多くのページで同じアイコンを使うなら、各ページのHTMLに `<symbol>` を書くより転送量が減ります。{/* 要確認: 出典なし。外部ファイルのスプライトを選ぶ場面 */}

ただし、外部のファイルを参照できるのは、ページと同じオリジンのファイルだけです。SVG 2の仕様は、`<use>` で別のオリジンのファイルやdata URLを参照することを認めておらず、CORSで許可する方法もありません。アイコンのファイルを別のオリジンのCDNに置く構成では、外部のファイルのスプライトは使えません。

### スプライトのアイコンの代替テキスト

代替テキストの付け方は、「[インラインSVGの代替テキスト](#インラインsvgの代替テキスト)」と同じです。意味のあるアイコンは、参照する側の `svg` 要素に `role="img"` と `aria-label` を付けます。装飾だけのアイコンや、名前を視覚的に隠したテキストで添えるアイコンは、`aria-hidden="true"` にします。違うのは、`<symbol>` をまとめた `svg` 要素も、`aria-hidden="true"` と `display: none` で読み上げと表示の両方から外しておく点です。{/* 要確認: 出典なし。スプライトをまとめた svg 要素の隠し方 */}

### スプライトを選ぶ場面

スプライトは、インラインSVGの書き方の1つです。文字色に合わせられることと代替テキストの付け方はインラインSVGと同じで、違うのは形をどこに書くかだけです。同じアイコンが1ページに何度も出てくるとき（一覧の各行のアイコンなど）や、サイトの全体で同じ種類のアイコンを使い回すときは、スプライトを選びます。1か所にしか出てこないアイコンや、図形ごとに色や動きを変えるアイコンは、インラインSVGをそのまま置きます。HTMLに手を入れずにCSSだけで足す装飾なら、これまでどおり `mask-image` を選びます。{/* 要確認: 出典なし。スプライトとインラインSVGの使い分け */}
