カードのどこを押しても記事へ移動させたいときは、カードを `<a>` で包まず、見出しのリンクの `::after` をカードいっぱいに広げます。リンクのテキストは見出しだけのまま、押せる範囲だけがカード全体に広がります。

## カードを `<a>` で包む方法の問題

記事の一覧のカードでは、見出しだけでなくカードのどこを押しても記事へ移動させたいことがよくあります。いちばん簡単なのは、カード全体を `<a>` で包む方法です。しかし、この方法ではカードの中身すべてがリンクのテキストになり、スクリーンリーダーは日付やカテゴリーまで続けて読み上げます。カードの中にカテゴリーへのリンクを置きたくても、リンクの中にリンクは入れられません。

## 見出しのリンクを広げる

そこで、リンクは見出しの `<a>` だけにし、その `::after` をカードいっぱいに広げます。見た目の上ではカードのどこを押してもリンクが反応しますが、リンクのテキストは見出しだけです。

```css title="🙆‍♂ Recommended: 見出しのリンクの ::after をカードいっぱいに広げる"
@scope (.scoped.article-card) to (.scoped) {
  :scope {
    position: relative;
    isolation: isolate;

    &:has(._heading-link:focus-visible) {
      box-shadow: 0 0 0 6px Canvas;
      outline: 3px solid CanvasText;
      outline-offset: 3px;
    }
  }

  ._heading-link {
    &::after {
      content: "";
      position: absolute;
      inset: 0;
    }

    /* フォーカスリングはカードの外周に出すので、ベーススタイルの box-shadow を初期値に戻し、outline は色だけを透明にする */
    &:focus-visible {
      box-shadow: initial;
      outline-color: transparent;
    }
  }

  ._category-link {
    position: relative;
    z-index: var(--z--forwards);
  }
}
```

カードに `position: relative` を指定し、`::after` の配置の基準にします。フォーカスリングは、リンクの周りではなく `:has(._heading-link:focus-visible)` でカードの外周に出します。見出しのリンクにフォーカスしたとき、押せる範囲（カード全体）とリングの範囲が一致するからです。リングの形は、ベーススタイルの二重のリング（「[8-2 ベーススタイルに書くもの](/reset/base-styles/)」）と同じにし、ページのほかの要素とそろえます。カテゴリーのリンクにフォーカスしたときは、カードではなくカテゴリーのリンクにリングが出ます。`:has()` の引数を `._heading-link:focus-visible` に絞っているからです。カードの中にほかのリンクを置くときは、`position: relative` と `z-index: var(--z--forwards)` で `::after` より手前に重ねます。

リンク自身のリングのうち、ベーススタイルで内側に描いた `box-shadow` は、`initial` で初期値の `none` に戻します。`outline` は `outline: none` で消さずに、色だけを透明にします。強制カラーモードでは `outline` の色がシステムカラーに置き換わるので、リングの形が残ります。`outline: none` で消すと、強制カラーモードでリングが描かれなくなるので使いません（「[8-3 グローバルに書いてはいけないもの](/reset/global-pitfalls/)」のルール `no-outline-none`）。

## 補足と注意点

この方法では、`::after` がカードの上に重なるので、カードの中の文章をドラッグして選択できません。カードの中の文章を選択させる必要があるカードには、この方法を使いません。押せる範囲を見出しのリンクだけにするか、カードのどこを押しても移動させる要件も残るなら、JavaScriptでカードのクリックを拾います。カードの中にカテゴリーなどの別のリンクを置くカードでは、カードを `<a>` で包めないので、見出しのリンクを広げるこの方法を選びます。

文章を選択できないことを受け入れても、本書は `::after` を広げる方法を基本にします。CSSだけで実装でき、JavaScriptが動かない環境でもカード全体を押せるからです。以前はJavaScriptでクリックを拾う方法を使っていましたが、この2つの利点を優先して切り替えました。
