この章では、要素を並べる、間を空ける、重ねるといったレイアウトを、実際に組み立てる方法を扱います。レイアウトは、まず親の `grid-template` で配置と余白を決められないかを考え、子要素の側には配置のための指定をなるべく書きません。そのうえで、内容の長さや量が変わっても崩れないように、守りの指定を加えます。各方式の規則は、第7章「[レイアウトの仕組み](/layout/)」で説明しています。

私が勧めているのは、FlexboxではなくGridから考え始めることです。「1次元ならFlexbox、2次元ならGrid」という分け方が広まっていますが、1行の並びでもGridのほうが簡潔に書ける場面は多くあります。何でもFlexboxで組むと、子要素の側に幅の計算や打ち消しの指定が散らばり、レイアウトの全体像がどこにも書かれていない状態になりがちです。一方で、見出しと段落が続く文章のように、要素の関係で間隔が変わる流れは、通常フローのまま組みます。

もうひとつは、内容が変わっても崩れないことです。内容が変わることを前提にする理由は「[2-2 CSSで考えるための6つの視点](/design-mindset/css-mindset/#内容が変わる前提で書く)」で説明しました。この章では、その変化を種類ごとに分けて扱います。文章の長さや要素の高さの変化は「[11-3 サイズと内容の変化に耐える](/layout-practice/defensive/)」で、それでも起きたはみ出しは「[11-4 はみ出しとスクロール](/layout-practice/overflow/)」で扱います。件数や区画の有無の変化は「[11-5 件数で配置を組み替える](/layout-practice/quantity-layouts/)」で、入りきらない文字の切り詰めは「[11-16 文字の切り詰めと読み込み中の表示](/layout-practice/truncation-and-skeletons/)」で扱います。

以前は、要素の間隔を子の `margin-bottom` で空けて最後の要素だけ `:last-child` で打ち消し、カードの高さを `height` でそろえる書き方がよく使われていました。どちらも、要素の数や文章の長さが変わると、打ち消しの漏れやはみ出しが起きます。この章では、間隔を親の `gap` や次兄弟結合子で決め、高さは `min-block-size` や `aspect-ratio` で下限と比率だけを決めます。

## この章で判断できるようになること

この章を読むと、作るものを見て、通常フロー、Grid、Flexbox、`float` のどれで組むかを決め、配置と余白を親と子のどちらに書くかを決められるようになります。長い見出しや画像のない記事、件数の増減があっても、どの要素が伸び、どこで折り返し、どこを切り取るかを、書く前に決められます。横スクロールが出たときの原因の特定や、並べ替えた配置で読み上げ順がずれないかの確認も、実装の段階で行えます。

## 最初に押さえるルール

次のルールを先に押さえ、ほかのルールは、該当する場面で付録A「[ルール一覧](/appendix/rules/)」から引けば足ります。

- [`grid-template-first`](/layout-practice/choosing/#rule-grid-template-first)：レイアウトを組むときは、まず親の `grid-template` で子要素の配置と大きさを決められないかを検討します。
- [`gap-over-child-margin`](/layout-practice/spacing/#rule-gap-over-child-margin)：FlexboxやGridの子要素の間隔は、子要素の `margin` ではなく、親の `gap` で作ります。
- [`block-margin-with-sibling-combinator`](/layout-practice/spacing/#rule-block-margin-with-sibling-combinator)：要素の間の縦の `margin` は、`& > * + *` のようなセレクタで、後ろの要素の `margin-block-start` に付けます。
- [`min-block-size-over-fixed-height`](/layout-practice/defensive/#rule-min-block-size-over-fixed-height)：高さは `block-size` で固定せず、`min-block-size`、`max-block-size`、`aspect-ratio` で決めます。
- [`overflow-clip-over-hidden`](/layout-practice/overflow/#rule-overflow-clip-over-hidden)：はみ出しを切り取るだけなら、`overflow: hidden` ではなく `clip` を使います。

## この章の判断のまとめ

レイアウトの手法は、次元の数ではなく、配置を何が決めるかで選びます。親の指定で決めるならGrid、子の中身の量で決まるならFlexbox、文章の流れなら通常フロー、文章を回り込ませるなら `float` です。余白は間隔の決まり方から選び、一律なら親の `gap`、構成が決まっていて間ごとに違うなら空のグリッドセル、前後の要素の種類や有無によって変わるなら、次兄弟結合子で選んだ後ろの要素の `margin-block-start` を使います。

横スクロールが出たら、切り取る前にはみ出している要素を特定し、固定の幅や高さと、親の幅を上限にしていない最小の長さを疑います。重なり順がおかしければ、z-indexを大きくする前にスタッキングコンテキストを確かめ、見た目の順番を変えたら、読み上げとフォーカスの順番がDOMの順番のままであることを確かめます。
