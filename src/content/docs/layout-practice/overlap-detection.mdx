飾りの図形が本文に近づきすぎたら隠す処理は、CSSだけで作れます。アンカーポジショニングで飾りと本文の間に測定用の要素を置き、その中身がはみ出したかどうかをスクロールタイムラインで調べ、アニメーションでフラグ `--_overlapping` を `--false` から `--true` に切り替えます。飾りはスタイルクエリでフラグを読み、`--true` の間だけ隠れます。閾値を書かないので、本文の幅や飾りの大きさを変えても、CSSのほかの箇所を直す必要がありません。

この技法は、Safari 18などの未対応の環境では働きません。そのため、本書では、隠れても内容と操作に影響しない装飾にだけ使い、指定はすべて `@supports` の中に書きます。重ならないレイアウトを組めるなら、そちらを先に選びます。

この節の仕組みは、アンカーポジショニング、スクロール駆動アニメーション、スタイルクエリの3つを組み合わせたものです。アンカーポジショニングは「[11-8 アンカーポジショニング](/layout-practice/anchor-positioning/)」で、スタイルクエリのフラグは「[10-6 スタイルクエリで状態を伝える](/components/style-queries/)」で、スクロール駆動アニメーションは「[18-9 スクロールに合わせて動かす](/motion/scroll-driven/)」で説明しています。どれも、この節で使う範囲はこの節の中で説明します。

## 飾りが本文に重なる場面

見出しの横や見出しの背後に、絶対配置で飾りの図形を置くデザインはよくあります。広い画面では、飾りと本文の間に十分な間隔があります。画面を狭めていくと、本文の箱は中央に寄ったまま飾りへ近づき、やがて文字が飾りの上に載ります。飾りの色が濃いと、重なった部分の文字が読みにくくなります。

ふつうは、メディアクエリかコンテナサイズクエリで、狭いときに飾りを消します。しかし、その閾値は、本文の最大幅、飾りの大きさ、飾りの位置、余白を足し合わせて逆算した値です。どれかを変えると閾値も直す必要があります。直し忘れたり計算を誤ったりすれば、重なっているのに飾りの消えない幅が残ります。文字サイズの設定で本文の箱が広がる場合も、`px` で足し合わせた閾値とはずれます。{/* 要確認: 出典なし */}

JavaScriptで判定する方法もあります。ただ、`IntersectionObserver` が調べるのは、対象の要素とルート（ビューポートか祖先の要素）との交差です。兄弟の関係にある飾りと本文の重なりは、`ResizeObserver` で大きさの変化を受け取り、そのたびに `getBoundingClientRect()` で2つの矩形を比べることになります。飾りを隠すかどうかという見た目だけの判断のために、スクリプトを読み込み、レイアウトが変わるたびに座標を計算する処理を動かすことになります。

CSSで判定できれば、飾りの見た目に関わる指定が、コンポーネントのCSSの中にまとまります。CSSの機能だけで組むので、スクリプトの読み込みや実行を待たずに判定が反映されます。{/* 要確認: 出典なし */}未対応の環境では指定が無視されて、飾りが表示されたままになるだけなので、装飾に限ればプログレッシブ・エンハンスメントとして扱えます。

## 間隔を「はみ出し」として測る

まず、2つの要素の間隔を、ある要素の中身がはみ出すかどうかに置き換えます。飾りと本文にそれぞれアンカーの名前を付け、測定用の空の要素を絶対配置にして、`anchor()` で飾りの行末側の辺から本文の行頭側の辺までの範囲に置きます。こうすると、測定用の要素の幅は、飾りと本文の間隔と一致します。

次に、測定用の要素に `overflow-x: auto` を指定し、中に幅20pxの擬似要素を入れます。間隔が20px以上あれば中身は収まり、20pxを切ると中身がはみ出して、測定用の要素はスクロールできる状態になります。20pxは、飾りと本文の間に確保したい最小の間隔です。この値を変えれば、飾りを隠し始める間隔を変えられます。

測定用の要素は見せるためのものではないので、`scrollbar-width: none` でスクロールバーを隠し、`pointer-events: none` でマウスの操作も受けないようにします。HTMLでは `inert` 属性を付けます。`overflow-x: auto` の要素はスクロールコンテナで、中身がはみ出すとスクロールできる状態になります。スクロールできる要素をキーボードで選べるブラウザでは、見えないこの要素にもフォーカスが移るからです。`inert` を付けると、フォーカスを受け取らず、支援技術からも隠れます。

アンカーの名前は、ルートの `anchor-scope` でコンポーネントの中に限ります。同じコンポーネントをページに複数置くと、同じ名前のアンカーも複数でき、別のコンポーネントの飾りや本文を基準に測ってしまうからです。理由は「[11-8 アンカーポジショニング](/layout-practice/anchor-positioning/)」のルール `anchor-scope-for-repeated-components` と同じです。

## はみ出しをフラグに変える

はみ出しの有無は、そのままではスタイルの条件に使えません。そこで、スクロールタイムラインの性質を使います。測定用の要素に `scroll-timeline: --decoration-gap inline` を指定すると、その要素の行方向のスクロール位置を進み具合にしたタイムラインができます。仕様では、スクロールできるはみ出しがない間、このタイムラインは無効（inactive）になり、無効なタイムラインに結び付けたアニメーションは効果を持ちません。つまり、アニメーションが働くのは、間隔が20pxを切ってはみ出している間だけです。

アニメーションは、測定用の要素ではなく、コンポーネントのルートに結び付けます。ルートの値は継承と問い合わせによって、飾りから読めるからです。ただし、スクロールタイムラインの名前は、既定ではそれを作った要素とその子孫からしか参照できません。ルートに `timeline-scope: --decoration-gap` を指定すると、子孫の測定用の要素が作ったタイムラインを、ルートの `animation-timeline` から参照できるようになります。

キーフレームには、最初と最後で同じ値 `--_overlapping: --true` を書きます。登録していないカスタムプロパティのアニメーションは補間されず、進み具合の半ばで値が切り替わります。最初と最後を同じ値にしておけば、スクロール位置がどこでも、タイムラインが有効な間は常に `--true` が当たります。測定用の要素はスクロールしないので、進み具合は0のままですが、それでも `--true` になります。

ルートには、デフォルト値 `--_overlapping: --false` を通常の宣言で書いておきます。アニメーションの値は、カスケードで通常の宣言より優先されるので、タイムラインが有効な間だけ `--true` に置き換わります。デフォルト値を書くのは、カスタムプロパティが継承するからでもあります。書かないと、このコンポーネントを入れ子にしたとき、外側のコンポーネントで立った `--true` を受け継ぎ、内側の飾りまで隠れます。フラグの値は、`1` や `true` ではなく `--true` と `--false` にします。ルール `state-flag-values` は、オンとオフの2値のフラグをこの2つにそろえ、書き間違いに気付きやすくする決まりです（「[10-6 スタイルクエリで状態を伝える](/components/style-queries/)」）。

最後に、飾りの側で `@container style(--_overlapping: --true)` を書き、条件が成り立つ間だけ `opacity: 0` にします。名前を書かないスタイルクエリは親を問い合わせ、飾りの親はルートなので、ルートで切り替わったフラグを読めます。

```css title="🙆‍♂ Recommended: はみ出している間だけフラグを --true にし、飾りはスタイルクエリで隠す" from="layout-practice/overlap-detection"
@keyframes --detect-overlap {
  from,
  to {
    --_overlapping: --true;
  }
}

@scope (.scoped.feature-intro) to (.scoped) {
  :scope {
    --_overlapping: --false;

    position: relative;

    @supports (anchor-name: --decoration) and (animation-timeline: scroll()) {
      anchor-scope: --decoration, --content;
      animation-name: --detect-overlap;
      animation-timing-function: linear;
      animation-fill-mode: both;
      animation-timeline: --decoration-gap;
      timeline-scope: --decoration-gap;
    }

    & > ._decoration {
      position: absolute;
    }
  }

  ._decoration {
    anchor-name: --decoration;

    @container style(--_overlapping: --true) {
      opacity: 0;
    }
  }

  ._content {
    anchor-name: --content;
  }
}
```

次のデモでは、見出しと段落を収めた箱の左上に、飾りの円を置いています。円は `z-index: var(--z--backwards)` で本文の後ろに置き、本文の箱には背景色を付けています。重なった瞬間に円が消えなくても、文字は箱の背景の上にあるので読めます。

<Demo title="飾りの円と本文の間隔が20pxを切ると、円が消える" html={overlapHtml} css={overlapCss} />

デモの幅を狭めると、円と本文の箱の間隔が20pxを切ったところで円が消え、広げると再び表示されます。閾値をメディアクエリで書いていないので、本文の最大幅や円の大きさを変えても、CSSのほかの箇所を直す必要はありません。

測定用の要素は、`@supports` の外では `display: none` にしています。アンカーを解決できない空の要素を、未対応の環境で配置させないためです。`@supports` の条件には、アンカーポジショニングの `anchor-name` と、スクロール駆動アニメーションの `animation-timeline: scroll()` の両方を書いています。とくに `animation-timeline` の確認は欠かせません。`animation-timeline` を知らない環境では、ルートのアニメーションが文書のタイムラインで再生され、長さ0秒と `both` の指定によって最後のキーフレームの値が残り続けます。その環境では、フラグが常に `--true` になり、間隔に関係なく飾りが消えます。

## 使ってよい範囲

本書では、この技法を、隠れても内容と操作に影響しない装飾にだけ使います。隠す対象が本文やボタンだと、未対応の環境と対応した環境で、読める内容や使える操作が変わるからです。たとえば、重なったら補足の説明を隠す使い方では、対応した環境の読者だけが、その説明を読めなくなります。ナビゲーションを1行に収まらなくなったら折りたたむ処理は、離れた2つの要素の間隔ではなく、ナビゲーション自身の溢れを測れば作れます。アンカーポジショニングが要らず、未対応の環境では折りたたんだ表示になるので、「[13-9 収まらなくなったらナビゲーションを折りたたむ](/responsive/overflow-collapse/)」の書き方を使います。

装飾に限っても、飾りが本文に重なったまま表示される時間はあります。未対応の環境では常に表示されますし、対応した環境でも、20pxという間隔は見た目の目安で、飾りの形によっては、測っている矩形より先に図形の端が文字に近づきます。そのため、飾りは本文の後ろに置き、本文には背景色を付けて、重なっても文字を読めるようにしておきます。この技法は、その上で見た目を整えるために使います。

重ならないレイアウトを組めるなら、そのほうが単純です。間隔に余裕を持たせられるなら、飾りをGridの列に置けば、飾りと本文は同じ行に並び、重なりません（「[11-6 重なりと全幅](/layout-practice/layering/)」）。飾りを本文の背後に敷くデザインで、本文の幅に合わせて飾りを隠したいときに、この技法を検討します。{/* 要確認: 出典なし */}

## 対応状況と未対応の環境での見え方

この技法には、アンカーポジショニング、スクロール駆動アニメーション（`timeline-scope` を含む）、カスタムプロパティのスタイルクエリの3つが必要です。

3つとも使えるのは、Chrome系のブラウザとSafari 26以降です。Firefoxは、アンカーポジショニングに147から、スタイルクエリに151から対応しましたが、スクロール駆動アニメーションには安定版がまだ対応していません（MDNのブラウザ互換性データとweb-featuresのデータで確認）。本書の対象のSafari 18系は、アンカーポジショニングに対応していません。

未対応の環境では、`@supports` の条件が成り立たないので、ルートのアニメーションも測定用の要素の配置も働きません。フラグはデフォルト値の `--false` のままで、飾りは表示され続けます。狭い画面では飾りと本文が重なりますが、飾りは本文の後ろにあり、本文には背景色があるので、文字は読めます。対応した環境との違いは、飾りが見えるかどうかだけです。

`@supports` で調べているのは `anchor-name` と `animation-timeline` で、スタイルクエリは調べていません。スタイルクエリに対応していない環境では、飾りの `@container style()` の中が無視され、やはり飾りが表示されたままになります。どの機能が欠けても、飾りは隠れずに残るので、内容が読めなくなる組み合わせはありません。
